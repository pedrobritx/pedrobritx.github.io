# pedrobritx.github.io

This repository serves the GitHub Pages user site for [`britx.me`](https://britx.me/).

The root domain is reserved for the personal portfolio hub. Project repositories should remain GitHub Pages project sites and be exposed as first-level paths, for example:

- `https://britx.me/framio/`
- `https://britx.me/verbalis/`
- `https://britx.me/nova/`

The `CNAME` file intentionally contains only `britx.me`; do not assign the apex custom domain to individual project repositories.
